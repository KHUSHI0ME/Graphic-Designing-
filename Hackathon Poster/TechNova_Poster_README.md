# TechNova 2026 — Event Poster Design

A daily graphic design practice project focused on building professional poster design skills — typography, visual hierarchy, spacing, and color theory — through iterative, critiqued revisions.

## 📋 Brief

Design an Instagram + print poster for **TechNova 2026**, a college hackathon event, following a dark tech aesthetic.

**Requirements:**
- Event name, tagline (*"Build. Break. Repeat."*), date/time, and a clear call-to-action
- Max 3 colors, max 2 fonts
- Portrait orientation (1080×1350)

## 🛠️ Tools

Designed in **Canva**, following a self-directed design brief with structured critique after each revision (typography, hierarchy, spacing/alignment, color, and overall polish, each scored against professional standards).

## 🔁 Design Process

The poster went through 4 iterations, each addressing specific critique from the previous round:

| Round | Key Change | Score |
|---|---|---|
| v1 | Initial layout — serif font, no CTA distinction | 6.4 / 10 |
| v2 | Switched to sans-serif (Poppins-style) font, fixed typos, added gold accent color to CTA | 7.6 / 10 |
| v3 | Added a decorative border (color clashed with existing palette) | 7.4 / 10 |
| v4 (final) | Removed border, restored clean 3-color palette, fixed final typo | **7.8 / 10** |

## 🎯 Skills Practiced

- **Typography** — choosing fonts that match brand tone (sans-serif for a modern tech feel vs. serif reading as too formal)
- **Visual hierarchy** — using size and weight, not just color, to guide the eye
- **Color restraint** — sticking to a disciplined 3-color system and knowing when an "improvement" actually breaks it
- **Iteration based on critique** — treating design as a process, not a single draft

## 📈 Outcome

Improved from **6.4 → 7.8 / 10** across 4 rounds, resolving font mismatch, a recurring typo, and color palette discipline. Alignment consistency between the logo and body text was identified as the one open improvement area for future work.
